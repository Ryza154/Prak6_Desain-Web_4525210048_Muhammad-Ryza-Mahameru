# NewsHub - Portal Berita

Website portal berita sederhana untuk tugas wireframe (desktop dan mobile).

## Isi halaman

- Header dengan pencarian dan menu kategori
- Breaking news
- Berita utama dan tiga berita terbaru
- Sidebar berita populer dan formulir newsletter
- Navigasi bawah khusus mobile

## Struktur folder

```text
Portal_Berita_NewsHub/
├── index.html
├── style.css
├── README.md
├── Laporan_Proyek.txt
└── images/   (8 ilustrasi SVG)
```

## Cara menjalankan

1. Ekstrak ZIP, lalu buka folder `Portal_Berita_NewsHub` di VS Code.
2. Klik kanan `index.html` > **Open with Live Server**, atau buka langsung di browser.
3. Jaga `index.html`, `style.css`, dan folder `images` tetap satu folder.

## Catatan

- Isi berita hanya contoh, bukan berita sungguhan.
- Pencarian dan newsletter belum terhubung ke database, hanya menampilkan pesan demo.
- Font DM Sans dari Google Fonts butuh internet. Tanpa internet, browser memakai Arial.
